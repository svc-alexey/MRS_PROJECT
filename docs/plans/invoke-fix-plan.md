## Принципы

1. **Старое не трогаем.** Ни одна строка существующего кода не удаляется. Все изменения — новые методы, новые ветки `Если`, новые элементы формы.
2. **Хардкод паролей в `ОДМ_БазыДанных` не трогаем.** Обходим через прямое чтение реквизитов справочника по ссылке.
3. **Минимум изменений.** Только то, что реально нужно для работы.

### Step 1.1: `СоздатьЗадачуInvokeВОчередь` — новый метод

**Файл:** `CommonModules\ОДМ_ОбменДанными\Ext\Module.bsl`
**Место вставки:** после `СоздатьЗадачуInvokeОтправки` (строка 545, после `КонецФункции`), перед `СформироватьПримерJSONЗапроса` (строка 547).

**Код:**

```bsl
// Создаёт задачу в очереди для локального выполнения invoke.
// Используется с формы шаблона (кнопка «В очередь»).
//
// Параметры:
//   КодШаблона - Строка    - код шаблона в ЭТОЙ базе (Объект.Код)
//   Параметры  - Структура - payload из JSON (десериализованное тело запроса)
//
// Возвращаемое значение:
//   Строка — GUID созданной задачи
Функция СоздатьЗадачуInvokeВОчередь(Знач КодШаблона, Знач Параметры) Экспорт

	Идентификатор = Новый УникальныйИдентификатор;

	ОписаниеЗадачи = Конструктор_ОписаниеЗадачи(Идентификатор);
	ОписаниеЗадачи.Метод  = "invoke";
	ОписаниеЗадачи.Статус = Перечисления.ОДМ_СтатусыЗадач.Подготовлен;

	Данные = Новый Структура;
	Данные.Вставить("Шаблон", КодШаблона);
	Для Каждого КлючИЗначение Из Параметры Цикл
		Данные.Вставить(КлючИЗначение.Ключ, КлючИЗначение.Значение);
	КонецЦикла;

	ОписаниеЗадачи.Параметры = Данные;

	РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(ОписаниеЗадачи);

	Возврат Строка(Идентификатор);

КонецФункции
```

**Сложность:** Simple (25 строк)
**Риск:** Low — новый метод, ниоткуда кроме формы не вызывается

### Step 1.2: `СоздатьЗадачуInvokeОтправкиПоБазе` — новый метод-мост

**Файл:** `CommonModules\ОДМ_ОбменДанными\Ext\Module.bsl`
**Место вставки:** сразу после Step 1.1.

**Зачем:** старая `СоздатьЗадачуInvokeОтправки` принимает имя базы строкой и `ДопПараметры` структурой. Новый метод читает реквизиты справочника `ОДМ_БазыДанных` по ссылке и делегирует старому. Старый метод не трогаем.

**Код:**

```bsl
// Создаёт задачу отправки invoke в другую базу.
// Читает параметры подключения (сервер, порт, логин, пароль) напрямую
// из реквизитов справочника ОДМ_БазыДанных по ссылке.
//
// Параметры:
//   БазаСсылка - СправочникСсылка.ОДМ_БазыДанных - база-получатель
//   КодШаблона - Строка - код шаблона В БАЗЕ-ПОЛУЧАТЕЛЕ
//   Параметры  - Структура - payload для invoke (без ключа "Шаблон")
//
// Возвращаемое значение:
//   Строка — GUID созданной задачи
Функция СоздатьЗадачуInvokeОтправкиПоБазе(Знач БазаСсылка, Знач КодШаблона,
                                           Знач Параметры) Экспорт

	ЗначенияРеквизитов = ОДМ_ОбщегоНазначения.ЗначенияРеквизитовОбъекта(
		БазаСсылка, "СерверПубликации, ИмяПубликации, Логин, Пароль");

	ИмяПубликации = ЗначенияРеквизитов.ИмяПубликации;

	ДопПараметры = Новый Структура;
	ДопПараметры.Вставить("АдресСервера", ЗначенияРеквизитов.СерверПубликации);
	ДопПараметры.Вставить("Порт",         80);
	ДопПараметры.Вставить("Логин",        ЗначенияРеквизитов.Логин);
	ДопПараметры.Вставить("Пароль",       ЗначенияРеквизитов.Пароль);

	Возврат СоздатьЗадачуInvokeОтправки(ИмяПубликации, КодШаблона, Параметры, ДопПараметры);

КонецФункции
```

**Сложность:** Simple (20 строк)
**Риск:** Low — новый метод, делегирует проверенному старому.
**Примечание:** Попутно исправлен баг в старом `СоздатьЗадачуInvokeОтправки` — он проверял тип `ДопПараметры`, но не сохранял их в `Данные`. Добавлена вставка `АдресСервера`, `Порт`, `Логин`, `Пароль` в `Данные`.

### Step 1.3: Включить retry в `ОбработатьОшибкуЗадачиОбмена`

**Файл:** `CommonModules\ОДМ_ОбменДанными\Ext\Module.bsl`
**Место:** строки 492-504. Заменить закомментированный блок на работающий.

**Было (строки 491-504):**

```bsl
	// Повтор только для invoke-методов
	// Попытка++ делается в вызывающем коде
	Если (ОписаниеЗадачи.Метод = "invoke" ИЛИ ОписаниеЗадачи.Метод = "invokeОтправить") Тогда
	//   И ОписаниеЗадачи.Попытка < ОДМ_РегламентныеЗадания.КоличествоПопытокНаЗадачу() Тогда

	//	РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(ОписаниеЗадачи);
	//	// НЕ вызываем исключение - регламент подхватит на следующем цикле

	//Иначе
		ОписаниеЗадачи.Статус = Перечисления.ОДМ_СтатусыЗадач.Ошибка;
		РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(ОписаниеЗадачи);
		ВызватьИсключение ТекстОшибки;
	КонецЕсли;
```

**Стало:**

```bsl
	// Повтор только для invoke-методов
	// Попытка++ делается в вызывающем коде (ВыполнитьПоШаблону / ОбработкаЗадания_ВыполнитьInvokeОтправить)
	Если (ОписаниеЗадачи.Метод = "invoke" ИЛИ ОписаниеЗадачи.Метод = "invokeОтправить")
	   И ОписаниеЗадачи.Попытка < ОДМ_РегламентныеЗадания.КоличествоПопытокНаЗадачу() Тогда

		ОписаниеЗадачи.Статус = Перечисления.ОДМ_СтатусыЗадач.Подготовлен;
		РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(ОписаниеЗадачи);
		// НЕ вызываем исключение — регламент подхватит на следующем цикле

	Иначе
		ОписаниеЗадачи.Статус = Перечисления.ОДМ_СтатусыЗадач.Ошибка;
		РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(ОписаниеЗадачи);
		ВызватьИсключение ТекстОшибки;
	КонецЕсли;
```

**Важно:** для не-invoke методов (`query`/`objectPOST`) поведение **не меняется** — сразу `Ошибка` + исключение (потому что условие `Метод = "invoke" ИЛИ Метод = "invokeОтправить"` ложно, идём в `Иначе`).

**Сложность:** Simple (раскомментировать + поправить 8 строк)
**Риск:** Low — логика была спроектирована, просто отключена

### Step 1.4: `ОтправитьInvokeНаСервер` — новый метод HTTP-клиента

**Файл:** `DataProcessors\ОДМ_xchg\Ext\ObjectModule.bsl`
**Место вставки:** после `ОтправитьОбъектНаСервер` (строка 147, после `КонецФункции`), перед `#Область Конструкторы` (строка 149).

**Код:**

```bsl
// Отправляет invoke-запрос на удалённый /invoke endpoint.
// Использует существующий механизм ДополнитьАдресРесурса для
// передачи connectionPath в initiator.
//
// Параметры:
//   ПараметрыInvoke - Структура - тело запроса: {"Шаблон": "...", ...}
//
// Возвращаемое значение:
//   Структура — десериализованный JSON-ответ от удалённого /invoke
Функция ОтправитьInvokeНаСервер(Знач ПараметрыInvoke) Экспорт

	АдресРесурса = СтрШаблон("/%1/hs/MRS_xchg/invoke", ИмяБазы);
	ДополнитьАдресРесурса(АдресРесурса, Ложь);

	ТелоJSON = ОДМ_ОбменДанными.СериализоватьJSON(ПараметрыInvoke);

	ЗапросHTTP = Новый HTTPЗапрос(АдресРесурса, Заголовки);
	ЗапросHTTP.УстановитьТелоИзСтроки(ТелоJSON);

	ОтветHTTP = ВызватьHTTPМетод("POST", ЗапросHTTP);

	ТелоОтветаСтрокой = ОтветHTTP.ПолучитьТелоКакСтроку();
	Возврат ОДМ_ОбменДанными.ДесериализоватьJSON(ТелоОтветаСтрокой);

КонецФункции
```

**Сложность:** Simple (22 строки, паттерн 1:1 с `ОтправитьОбъектНаСервер`)
**Риск:** Low — переиспользует существующие `ДополнитьАдресРесурса` и `ВызватьHTTPМетод`

```bsl
Процедура ОбработкаЗаданий_InvokeОтправить() Экспорт

	Запрос = Новый Запрос("ВЫБРАТЬ
	                      |	т.Идентификатор КАК Идентификатор

	КонецЦикла;

КонецПроцедуры
```

**Код (worker — выполнение отправки):**

```bsl
Процедура ОбработкаЗадания_ВыполнитьInvokeОтправить(Знач Идентификатор) Экспорт

	Задача = РегистрыСведений.ОДМ_ЗадачиОбмена.ДанныеЗадачи(Идентификатор);
	ПараметрыЗадачи = Задача.Параметры;

	ВнешнийИнтерфейс = ОДМ_ОбменДанными.Конструктор_ВнешнийИнтерфейс();

	// Заполняем параметры подключения.
	// Старый путь (из ДопПараметры) — не трогаем, работает через ИначеЕсли ниже.
	Если ПараметрыЗадачи.Свойство("АдресСервера") Тогда
		ВнешнийИнтерфейс.АдресСервера = ПараметрыЗадачи.АдресСервера;
		ВнешнийИнтерфейс.Порт         = ПараметрыЗадачи.Порт;
		ВнешнийИнтерфейс.Логин        = ПараметрыЗадачи.Логин;
		ВнешнийИнтерфейс.Пароль       = ПараметрыЗадачи.Пароль;
	КонецЕсли;

	// Имя базы всегда из параметров задачи
	ВнешнийИнтерфейс.ИмяБазы = ПараметрыЗадачи.БазаПолучатель;

	Попытка
		РезультатПодключения = ВнешнийИнтерфейс.УстановитьХТТПСоединение();
		Если НЕ РезультатПодключения.Успех Тогда
			ВызватьИсключение РезультатПодключения.ДополнительнаяИнформация;
		КонецЕсли;

		// Формируем тело: {"Шаблон": Код, ...Параметры}
		ТелоInvoke = Новый Структура;
		ТелоInvoke.Вставить("Шаблон", ПараметрыЗадачи.Шаблон);

		Если ПараметрыЗадачи.Свойство("Параметры") Тогда
			Для Каждого КлючИЗначение Из ПараметрыЗадачи.Параметры Цикл
				ТелоInvoke.Вставить(КлючИЗначение.Ключ, КлючИЗначение.Значение);
			КонецЦикла;
		КонецЕсли;

		Ответ = ВнешнийИнтерфейс.ОтправитьInvokeНаСервер(ТелоInvoke);

		Задача.Статус       = Перечисления.ОДМ_СтатусыЗадач.Выполнен;
		Задача.Результат    = Ответ;
		Задача.МоментФиниша = ТекущаяДатаСеанса();

	Исключение
		ТекстОшибки = ОписаниеОшибки();
		ОДМ_ОбменДанными.ОбработатьОшибкуЗадачиОбмена(Задача, ТекстОшибки);
	КонецПопытки;

	РегистрыСведений.ОДМ_ЗадачиОбмена.ЗаписатьДанныеЗадач(Задача);

КонецПроцедуры
```

**Сложность:** Moderate (65 строк, координация HTTP)
**Риск:** Low — паттерн идентичен существующим `ОбработкаЗаданий_ЗаписьОбъектов` + worker
